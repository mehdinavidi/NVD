📦 Installationsanleitung

Schritt 1: ZIP herunterladen

  1. Klicke auf den Button Jetzt herunterladen
  2. Speichere die Datei Nexus-ips.zip auf deinem Computer

Schritt 2: ZIP entpacken

  1. Rechtsklick auf Nexus-ips.zip
  2. Wähle "Alle extrahieren..." oder "Entpacken nach..."
  3. Wähle einen Speicherort (z.B. Desktop oder Dokumente)

Schritt 3: Apps starten

  1. Öffne den entpackten Ordner Nexus-ips
  2. Doppelklick auf Apps-Hub-Scrollable.html
  3. Die Hauptseite öffnet sich in deinem Browser

✅ Das funktioniert offline:

  • ✓ Alle Apps ohne Internet-Verbindung
  • ✓ Alle Bilder und Funktionen lokal verfügbar
  • ✓ Keine Installation erforderlich
  • ✓ Funktioniert auf Windows, Mac & Linux

💡 Tipp: Lesezeichen erstellen

Für schnellen Zugriff:

  1. Öffne Apps-Hub-Scrollable.html im Browser
  2. Drücke Strg + D (Windows) oder Cmd + D (Mac)
  3. Speichere als Lesezeichen

🔧 Systemanforderungen

  • Browser: Chrome, Firefox, Edge oder Safari
  • Keine zusätzliche Software nötig
