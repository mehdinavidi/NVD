🛠️ Technologie-Informationen

Diese App wurde mit reinen Web-Technologien entwickelt – keine Frameworks, keine externen Abhängigkeiten!

1. HTML5

  • Struktur der Webseite
  • Semantische Elemente (<input type="date">, <canvas>, <textarea>)
  • Meta-Tags für Mobile-Optimierung

2. CSS3

  • Komplettes Styling (kein CSS-Framework verwendet!)
  • Grid Layout für responsive Layouts
  • Flexbox für Ausrichtung
  • Media Queries für Mobile/Desktop/Print
  • CSS Transitions für Animationen
  • Dark Mode mit CSS-Variablen

3. Vanilla JavaScript (ES6+)

  • Keine Frameworks wie React, Vue oder Angular
  • Moderne JavaScript-Features:
    • Arrow Functions (=>)
    • Template Literals (``)
    • Async/Await
    • Array-Methoden (.map(), .filter(), .forEach())
    • Destructuring
  • Canvas API für die Unterschrift
  • LocalStorage API für Datenspeicherung
  • File API für JSON Import

4. Browser APIs

  • Canvas API – Unterschriften zeichnen
  • LocalStorage – Daten speichern
  • File API – Dateien importieren
  • Blob API – JSON exportieren
  • Print API – PDF erstellen (window.print())

📦 Besonderheiten

✅ Keine externen Abhängigkeiten
Kein npm, keine Bibliotheken
✅ Keine Build-Tools
Kein Webpack, Vite oder Bundler nötig
✅ Single File Application
Alles in einer HTML-Datei
✅ Offline-fähig
Funktioniert ohne Internet
✅ Keine Installation
Einfach im Browser öffnen
✅ Datenschutz
Alle Daten bleiben lokal

💡 Vorteile dieser Herangehensweise

  • Einfache Wartung – Nur eine Datei
  • Schnell – Keine großen Frameworks laden
  • Portabel – Überall verwendbar (USB-Stick, E-Mail, etc.)
  • Kompatibel – Läuft in jedem modernen Browser
  • Privat – Alle Daten bleiben lokal im Browser
